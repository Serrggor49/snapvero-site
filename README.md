# snapvero-site

Страницы приложения Snapvero (`com.gsu49.snapvero` в Google Play и App Store):
политика конфиденциальности, поддержка и корень. Публикуются GitHub Pages по адресу
https://serrggor49.github.io/snapvero-site/ — на него ссылаются обе карточки в сторах
и экран настроек приложения.

Репозиторий публичный ровно поэтому: Pages с приватного репозитория на бесплатном
плане не отдаются, а стороны, которые проверяют эти адреса, обязаны их открыть.
Ничего, кроме трёх статических страниц и общего `site.css`, здесь нет.

Источник — приватный репозиторий приложения, каталог `docs/`. Правки делаются там,
сюда приезжают командой `tools/site/publish.sh`: копия, коммит, push. Править файлы
здесь руками не нужно — при следующей публикации правка потеряется.
